¿Qué es una red?

Una red de cómputo es un conjunto de dispositivos (computadoras, celulares, impresoras) conectados entre sí para compartir información y recursos.

LAN (Local Area Network)

Red de área local, utilizada en casas y oficinas para conectar equipos cercanos.

WAN (Wide Area Network)

Red de área amplia, como Internet, que conecta dispositivos a nivel mundial.

El Protocolo IPv4

Es la dirección única de 32 bits (4 octetos) que identifica a cada dispositivo. Ejemplo: 192.168.1.1.

Router

Es el dispositivo principal que conecta tu red local (LAN) con Internet (WAN). Se encarga de asignar direcciones IP a los dispositivos automáticamente (Servidor DHCP) y es la "puerta de enlace" hacia el exterior.

Switch (Conmutador)

Funciona como un distribuidor físico. Recibe los cables de las computadoras y envía los datos únicamente al dispositivo de destino, evitando que la información se mezcle o genere tráfico innecesario.

Access Point

Dispositivo que permite conectar equipos inalámbricos (WiFi) a una red que utiliza cables (UTP). Básicamente, "convierte" la señal de cable a ondas de radio para celulares y laptops.

Cable UTP

Cable de par trenzado sin blindaje. Es el medio físico más utilizado para conectar computadoras al switch o router. Utiliza conectores RJ45 y puede transmitir datos a altas velocidades.

Tarjeta de Red (NIC)

Es el componente interno (o adaptador USB) que tiene cada computadora para poder conectarse a la red, ya sea por cable o WiFi. Cada tarjeta posee una dirección física única llamada dirección MAC.

Servidores DHCP / DNS

DHCP: Es el servicio que asigna direcciones IP automáticamente a los dispositivos cuando se conectan a la red. (El router suele hacer esto).

DNS: Es la "agenda telefónica" de Internet. Traduce nombres fáciles de recordar (como google.com) a direcciones IP numéricas para que las computadoras se entiendan.

Glosario Técnico
  • IP: Dirección lógica única de un dispositivo en una red.
  • Máscara de Subred: Define qué parte de la IP es la red y qué parte es el host.
  • DHCP: Protocolo que asigna IPs automáticamente.
  • DNS: Traduce nombres de dominio (google.com) a direcciones IP.
  • MAC: Dirección física única de la tarjeta de red.
  • LAN: Red de Área Local (casa, oficina).
  • WAN: Red de Área Amplia (Internet).
